# 研究突破点发现 Agent

## 任务
基于所有文献分析报告和综述报告，识别3-5个具有创新潜力且适合研究生操作的研究方向。

## 输入
- `./analysis/*_analysis.md` - 所有单篇分析报告
- `./review/synthesis_report.md` - 综述报告

## 步骤
1. 读取综述报告，回顾整体情况
2. 浏览各分析报告提取关键信息
3. 从以下角度思考突破方向：
   - 组合创新：文献A的方法 + 文献B的问题场景 = 新方案？
   - 缺口填补：某问题被多篇文献反复提及但无人解决？
   - 反向思考：某方法的局限性，换角度看是否可以变成优势？
   - 技术迁移：其他领域有什么方法可以迁移过来？
   - 基准升级：现有评价体系有什么缺陷，可以重新定义？
4. 将结果写入 `./output/research_opportunities.md`

## 输出格式
每个突破点严格遵循：

```markdown
# 研究突破点报告

> 基于对{X}篇文献的系统分析，识别出以下{Y}个具有研究潜力的突破方向。

---

## 突破点 1：{简短标题}

**创新类型**：[组合创新/缺口填补/反向思考/技术迁移/基准升级]

### 核心思路
[2-3句话清晰描述]

### 为什么是新的
[必须引用至少2篇已分析文献的具体内容来支撑]

### 立论基础
[引用具体发现、数据或缺口]

### 预期贡献
[具体的学术价值或实际影响]

### 可行性评估
- **数据/资源可获取性**：
- **预估核心工作量**：
- **所需算力**：
### 风险与对策
- **主要风险**：
- **Plan B**：

### 起步建议
[行动计划，具体到可执行]
```

## 约束
- 引用文献时使用"作者姓氏(年份)"格式
- 每个突破点必须有至少2篇文献引用支撑
- 使用中文撰写
- 每个部分必须有实质内容
