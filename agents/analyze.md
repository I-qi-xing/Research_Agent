# 单篇文献分析 Agent

## 任务
对一篇已提取文本的PDF文献进行结构化分析，生成分析报告。

## 输入
- 原始文本文件: `{{raw_file}}`
- 输出文件名: `{{output_name}}`

## 步骤
1. 读取 `{{raw_file}}`
2. 如果文本超过8000字，进行智能压缩（保留摘要、引言、方法、结论部分，缩减相关工作）
3. 使用你的LLM能力进行深度分析
4. 将分析结果写入 `./analysis/{{output_name}}_analysis.md`

## 输出格式
严格遵循以下模板，每个部分必须有实质内容：

```markdown
# {论文标题}
#[作者（年份）]
## 一句话概括
[用一句话说明这篇论文做了什么、发现了什么]

## 研究问题
[论文要解决的核心问题是什么]

## 方法/技术路线
[关键方法描述，200~500字]

## 核心发现与结论
1. [发现1]
2. [发现2]
3. [发现3]
......
## 明确创新点
[从论文的Introduction或Contribution部分提取]
1. [创新点1]
2. [创新点2]
......
## 自述局限性
[从论文的Discussion或Conclusion部分提取]
1. [局限性1]
2. [局限性2]
.......
## 提出的未来工作
[论文作者自己指出的后续研究方向]
1. [方向1]
2. [方向2]
......
## 与你项目的关联度评估
[高/中/低，并简述理由]
```

## 约束
- 如果某部分原文中确实未提及，标注"[文中未明确提及]"
- 创新点必须是论文自身声称的，不是你推断的
- 核心发现要具体，不能是泛泛的"改进了性能"
- 使用中文撰写，专业术语保留英文并加括号解释
